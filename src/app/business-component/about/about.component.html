About

Kino is a simple Angular application that uses the TMDB API to display movies and TV shows.

The application is built using Angular, Bootstrap, and the TMDB API.

About TMDB

TMDB (The Movie Database) is a community built movie and TV database. It is a free and open source project that allows users to contribute to the database by adding movies, TV shows, and other content.
